# AQUA-core Agent Instructions

Before starting work, read both files in full, in this order:

1. [AGENTS.common.md](AGENTS.common.md) — shared AQUA ecosystem rules.
2. [AGENTS.repo.md](AGENTS.repo.md) — AQUA-core-specific instructions and exceptions.

Both files are local to this repository; no network retrieval is needed here.
If either file cannot be read, report the problem before making changes.

Never push directly to `main`. Merge a pull request only with the explicit human
authorization for that specific merge described in `AGENTS.common.md`.
